# 个人财务管理系统 PRD

## 1. 产品概述

### 1.1 产品背景

随着个人消费场景日益丰富，许多人面临"不知道钱花到哪里去了"的困扰。同时，小微企业和个体户也急需简单好用的工具来记录日常收支、掌握经营状况。本产品旨在帮助用户简单、快速地记录每一笔收支，掌握财务状况，培养良好的财务管理习惯。

### 1.2 产品定位

一款**轻量、便捷、高颜值的个人/商户记账工具**，专注于日常收支记录与分析，让用户用最短的时间完成记账，并直观看到收支结构。

> **版本说明**：第一版为 Web 网页端（手机浏览器适配），后续版本将迭代支持移动端 APP 和小程序。

### 1.3 目标用户

| 用户类型 | 场景描述 |
|----------|----------|
| **个人用户** | 18岁以上年轻人、学生、上班族，记录日常消费，掌握消费习惯 |
| **家庭/情侣** | 共同管理家庭开支，分摊费用，了解共同消费情况 |
| **小微企业主** | 记录日常经营收支，简单统计收入支出，不需要复杂财务系统 |
| **个体户** | 记录商品进货、销售额、杂项开支，快速了解经营状况 |

## 2. 功能需求

### 2.1 功能优先级

#### P0 - 必须有（MVP）

| 功能 | 描述 | 适用用户 |
|------|------|----------|
| **用户注册/登录** | 用户名+密码注册和登录，数据隔离 | 全部 |
| **快速记账** | 选择分类 → 输入金额 → 保存，3步完成 | 全部 |
| **收支类型** | 支持"支出"和"收入"两种类型 | 全部 |
| **消费/收入分类** | 支出：餐饮、交通、购物、居住、娱乐、医疗、通讯、教育、其他；收入：工资、兼职、投资、礼金、其他 | 全部 |
| **月度账单** | 按月查看收支总额、结余及各类别占比 | 全部 |
| **收支趋势** | 近6个月收入/支出对比折线图 | 全部 |
| **首页今日概览** | 显示今日支出、收入及可用预算 | 全部 |

#### P1 - 应该有

| 功能 | 描述 | 适用用户 |
|------|------|----------|
| **预算设置** | 设置月度预算（支出上限），显示剩余可用额度，支持按分类设置子预算 | 个人、家庭、商户 |
| **账单搜索** | 按关键词/分类/日期范围/收支类型搜索历史记录 | 全部 |
| **数据导出** | 导出 CSV 格式账单数据 | 小微企业、个体户 |
| **月份结余统计** | 显示每月收入-支出的结余金额 | 全部 |

#### P2 - 可以有

| 功能 | 描述 | 适用用户 |
|------|------|----------|
| **多账本** | 区分"个人"、"家庭"、"生意"等不同账本 | 家庭、商户 |
| **周期性账单** | 记录每月固定支出（房租、订阅、工资等） | 全部 |
| **数据备份** | 本地数据备份与恢复（JSON格式） | 全部 |

### 2.2 用户认证流程

#### 注册流程

```
登录页 → 点击"注册" → 输入用户名/密码 → 确认密码 → 立即注册 → 自动登录 → 首页
```

#### 登录流程

```
启动应用 → 显示登录页（已注册用户）→ 输入用户名/密码 → 登录 → 首页
```

#### 登出流程

```
我的页 → 点击"退出登录" → 确认提示 → 返回登录页
```

### 2.3 记账流程

```
首页 → 点击"+"按钮 → 选择收支类型 → 选择分类 → 输入金额 → 可选添加备注 → 保存
```

### 3.3 数据模型

**用户 (User)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识符（UUID） |
| username | string | 用户名（唯一，长度3-20字符） |
| password | string | 密码（加密存储） |
| createdAt | string | 注册时间（ISO 8601格式） |

**账单记录 (Record)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识符（UUID） |
| userId | string | 所属用户ID |
| type | string | "expense" 或 "income" |
| amount | number | 金额（元），保留2位小数 |
| category | string | 分类ID |
| note | string | 备注（可选，最多50字） |
| createdAt | string | 创建时间（ISO 8601格式） |
| month | string | 所属月份（YYYY-MM），用于快速检索 |

**预算 (Budget)**

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | string | 所属用户ID |
| month | string | 月份（YYYY-MM） |
| limit | number | 月度支出预算上限（元） |
| categoryLimits | object | 按分类的子预算，key为分类ID，value为预算金额 |

**账本 (Ledger)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识符 |
| userId | string | 所属用户ID |
| name | string | 账本名称 |
| createdAt | string | 创建时间 |

## 4. 非功能需求

### 4.1 性能要求

- 页面首次加载时间 < 2秒
- 记账操作完成到反馈 < 500ms
- 支持至少 5000 条历史记录流畅查询
- 图表渲染流畅，无明显卡顿

### 4.2 安全性要求

- 密码使用不可逆加密存储（SHA-256 + salt）
- 用户间数据完全隔离，只能访问自己的数据
- 登录状态使用 Session Token 管理
- 密码找回功能可在后续版本迭代

### 4.3 兼容性要求

- **目标浏览器**：Chrome、Safari、Edge、Firefox 最新版本
- **设备适配**：手机浏览器优先（320px - 428px），平板和桌面端可用但非重点
- **操作系统**：iOS 13+、Android 9+

### 4.4 数据存储

- 使用浏览器 **LocalStorage** 存储
- 数据结构采用 JSON 格式
- 用户密码加密后存储
- 支持数据导出备份（CSV/JSON）

### 4.5 界面要求

- **设计风格**：简洁可爱，粉嫩色系，卡片式布局，圆角设计
- **主色调**：以粉色系为主，营造温馨可爱的氛围
- **字体**：圆润易读，支持系统默认字体
- **圆角**：卡片、按钮采用圆角设计（12px-16px），增加亲切感
- 支持**浅色模式**（深色模式可在后续版本迭代）
- 重点操作突出显示，次要信息适当弱化

- [x] 月度账单查看
- [x] 收支趋势折线图
- [x] 月份结余统计

**预计周期**：2-3周

**目标**：提升用户粘性和数据价值

**预计周期**：1-2周

## 7. 附录

### 7.1 竞品分析

| 竞品 | 优点 | 不足 | 本产品差异化 |
|------|------|------|--------------|
| 随手记 | 功能全面，专业财务 | 复杂，上手慢 | 轻量，简单，专注核心 |
| 钱迹 | 简洁，无广告 | 无云同步 | 本地优先，隐私安全 |
| 记账本 | 简单易用 | 功能单一 | 收支一体，趋势分析 |
| 支付宝记账 | 集成方便 | 依赖支付宝 | 独立产品，不依赖第三方 |

### 7.2 设计原则

1. **可爱感**：粉嫩色调，圆角卡片，温暖亲切
2. **轻量感**：大量留白，卡片式布局，操作区域集中
3. **活泼感**：彩色分类图标辅助快速识别
4. **信任感**：数据清晰呈现，保护用户隐私
5. **效率优先**：减少输入步骤，默认项智能化

### 7.3 设计风格关键词

| 关键词 | 说明 |
|--------|------|
| 粉嫩 | 整体色调偏暖粉、薰衣草紫、薄荷绿 |
| 可爱 | 圆角设计、柔和阴影、圆润字体 |
| 简洁 | 功能明确，不过度装饰 |
| 温暖 | 奶油白背景，护眼舒适 |

### 7.4 术语表

| 术语 | 定义 |
|------|------|
| 用户 | 通过用户名和密码注册的应用使用者 |
| 账单记录 | 一次收支行为，包含金额、分类、时间等信息 |
| 月度账单 | 某月所有账单记录的汇总 |
| 预算 | 用户设定的月度支出上限 |
| 结余 | 收入 - 支出 |
| 账本 | 用于区分不同用途的账目集合（如个人账本、家庭账本、生意账本） |
